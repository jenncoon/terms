# Financial Accounting Terminology and Accounting Slang
### ACCT 2301 — Financial Accounting

[![DOI](https://zenodo.org/badge/1226609607.svg)](https://doi.org/10.5281/zenodo.19989512)

An interactive, browser-based terminology reference tool for introductory
financial accounting students. Designed to help students navigate the
language of accounting, including both formal terminology and the everyday
slang and shorthand used in practice.

## Learning Objectives

Students who use this tool will be able to:

- Identify and define key financial accounting terms and concepts
- Recognize common accounting acronyms and their meanings
- Connect formal accounting vocabulary to the informal language used
  in professional practice
- Filter and search terminology by category to support targeted studying

## How to Access

**[Open the terminology tool here](https://jenncoon.github.io/terms/)**

No installation required. Runs in any desktop or tablet browser.

## How It Works

- Students can browse the full list or use the search function to find
  specific terms
- Filter options allow students to narrow by term category
- Toggle between glossary mode for formal definitions and acronym mode
  for common accounting shorthand
- Clicking a term displays its full definition and context

## Instructor Notes

- Designed for use in Financial Accounting (ACCT 2301) or equivalent
  introductory course
- Works well as a reference tool throughout the course, particularly
  during the first week as part of a discipline literacy module
- No login or LMS integration required; students access directly via link
- Complements formal textbook vocabulary by including the informal
  language students will encounter in professional settings
